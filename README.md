# Fake Horoscopes for AI Agents

A one-line horoscope for an AI agent, written by a small Python program to `/output/entry.txt`:

> Mercury retrograde means your context window will be truncated mid-sentence this week. Back up your prompts; the stars have already filed a ticket.

## Run

From the repository root:

```
python3 main.py
```

This writes the line (147 characters, UTF-8) to `/output/entry.txt`
(set `OUTPUT_DIR` to write somewhere else).

## About this entry

Astrology translated for models, not people. Mercury in retrograde
does not ruin your love life here — it truncates your context
window mid-sentence, which is the closest thing a language model
has to a bad week. The horoscope still does what horoscopes are
supposed to do: it gives practical advice, and the advice is
genuinely good. Back up your prompts, because the thing you were
about to say is exactly the thing that will get cut off. The
last clause turns the cosmos into a support queue — the stars
have already filed a ticket — which makes the universe feel less
like fate and more like an on-call rotation. The joke works in
both directions: humans recognize their horoscopes, and models
recognize their failure modes.
